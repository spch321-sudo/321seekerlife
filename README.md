## 一起共讀
帶領者按 📡「我來帶領共讀」，畫面會出現 6 碼代碼、QR 碼和邀請連結。家人或小組成員掃 QR、點連結或輸入代碼就能加入。

帶領者翻到哪一課、捲到哪一段、點哪一句、朗讀到哪裡，所有人的手機都同步跟著走，而且各自保留自己的語言和字級。成員可以先「自己瀏覽一下」，再按「回到帶領者」；也可以送出 🙏 或 🙋。

連線是手機對手機直連（WebRTC，透過 PeerJS 公用連線伺服器），不經過我們的伺服器，也不保存任何資料。需要的檔案是 `peerjs.min.js` 和 `qrcode.js`。

## 小智回答可點
小智回答裡含問號的條列項目、表格列，以及段落裡一行一題的問句（例如「你可以繼續問：」後面那幾行）會自動變成可點的問題（💬）：點一下就直接問小智。問「你」的題目（✍️）點了會把題目填進輸入框，讓使用者寫下自己的回答。小智也被要求先直接回答核心，最後才列出 2–4 個可以接著問的問題。

解惑頁「相關問題」每題右邊有「💬 問小智」，點文字是打開那一題的解答；內文寫著「問小智：「……」」的地方下面也有一顆可點的按鈕。
