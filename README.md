# 321慕道生活（321 Seeker Life）v1.0

陪伴慕道友一步一步認識耶穌，直到決志、受洗、委身教會與家組，並開始作屬靈父母的 PWA。繁／简／English 三語。

## 內容
- **24週慕道旅程**：六階段（探索、認識福音、回應、扎根、受洗、委身與傳承）× 每週五課，每課「看・聽・想・講・行」＋321光照；每週有背誦經文、相聚建議、相聚三問、給陪伴者的提醒。經文：新標點和合本（神版）、简体由繁轉、英文 WEB，全部逐字比對。
- **慕道解惑**：10類60題常見問題（神存在嗎、苦難、耶穌與聖經、拜拜祭祖、罪與救恩、信了以後的生活、教會、家人、決志受洗、內心與懷疑），每題有經文、這週可以試的一步、給陪伴者的提醒；可搜尋、收藏、朗讀、問小智。
- **旅程工具**：14個里程碑（屬靈生日、受洗等有慶祝動畫）、決志禱告、受洗預備（12項檢核、受洗日倒數、面談練習12題）、我的見證（三段式撰寫＋小智修飾＋美圖）。
- **陪伴**：慕道友記錄陪伴者與相聚日期、請他代禱；陪伴者可加入多位慕道友，記錄進度、信仰背景、里程碑、相聚與代禱，一鍵邀請本週課程，請小智給陪伴建議；陪伴者手冊（五原則、60分鐘相聚流程、福音橋、要避免的事、321・920・235）。
- **小智**：依身分（慕道友／陪伴者）與信仰背景（無宗教、民間信仰、佛道教、天主教、其他、曾去過教會）調整回答；預設「慕道友」回答對象。

## 321app 技能功能（與《321互動聖經》《321教會生活》相同）
GXA 工具箱（小智十種回答對象＋追問＋長度、讀經樂猜謎測驗與錯題本、美圖工作室含 AI 生圖／原圖／圖庫、配樂與錄音錄影、我的作品、聚會與奉獻）、逐句畫線與默想、真人朗讀（背景播放、鎖屏、跟讀標示、多音字修正）、繁简英切換、字級與深色、自動更新。

## 部署
把本資料夾所有檔案上傳到 GitHub repo（建議 `spch321-sudo/321seekerlife`）根目錄，Settings → Pages 開啟。更新時整批覆蓋即可，App 會自動換新版。
詩歌庫：可把《321互動聖經》的 `music.json` 與 `music/` 資料夾複製過來（美圖配樂用）。

## 一起共讀
帶領者按 📡「我來帶領共讀」，畫面會出現 6 碼代碼、QR 碼和邀請連結。家人或小組成員掃 QR、點連結或輸入代碼就能加入。

帶領者翻到哪一課、捲到哪一段、點哪一句、朗讀到哪裡，所有人的手機都同步跟著走，而且各自保留自己的語言和字級。成員可以先「自己瀏覽一下」，再按「回到帶領者」；也可以送出 🙏 或 🙋。

連線是手機對手機直連（WebRTC，透過 PeerJS 公用連線伺服器），不經過我們的伺服器，也不保存任何資料。需要的檔案是 `peerjs.min.js` 和 `qrcode.js`。

## 小智回答可點
小智回答裡含問號的條列項目、表格列，以及段落裡一行一題的問句（例如「你可以繼續問：」後面那幾行）會自動變成可點的問題（💬）：點一下就直接問小智。問「你」的題目（✍️）點了會把題目填進輸入框，讓使用者寫下自己的回答。小智也被要求先直接回答核心，最後才列出 2–4 個可以接著問的問題。

解惑頁「相關問題」每題右邊有「💬 問小智」，點文字是打開那一題的解答；內文寫著「問小智：「……」」的地方下面也有一顆可點的按鈕。

## 小智滿版與畫線
小智面板全螢幕、回答滿版、回答字級＝內文字級；標題列「A」鈕切換五段字級（與設定同步）。小智回答逐句可點：點一下畫線，再點開「這一句」面板，可換色、加範圍、寫默想、問小智、從這裡朗讀、做成美圖（引言裡的經文出處自動帶入）。畫線存在「我的畫線」，重開小智仍在。
